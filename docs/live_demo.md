# Live Demo

The live website presents the repository in under three minutes for a recruiter, hiring manager, or technical reviewer.

It shows:

- Project overview and positioning
- End-to-end reporting workflow
- Interactive dashboard with realistic fund-heavy portfolio data
- Load sample, edit holdings, add/remove rows, adjust weights, generate a deterministic report, and download Markdown
- Sample institutional-style report
- Public research source examples
- Quality-control checks
- Technical architecture
- Local run and Vercel deployment instructions

The live site runs browser-only calculations and deterministic report generation. It does not run the Python analytics engine, fetch live web research, call yfinance, call Ollama, or generate PDF.
